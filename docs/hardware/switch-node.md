# 스위치 노드 하드웨어 설계 (nRF54L15)

기존 벽스위치 뒤 매입박스에 들어가는 "이너릴레이" 형태이지만, **220V 릴레이가 없는
배터리 구동 무선 입력 노드**다. 기존 기계식 벽스위치의 접점을 감지해 CoAP over Thread
로 전등을 제어한다.

## 1. 설계 목표

| 항목 | 목표 |
|------|------|
| 폼팩터 | 기존 이너릴레이 매입 모듈과 동일 외형/사이즈 (벽 매입박스 삽입) |
| 전원 | 배터리 (CR2032 또는 2×AAA), 220V 미사용 |
| 무선 | Thread (802.15.4, 2.4GHz), nRF54L15 |
| 입력 | 기존 벽스위치 dry-contact 1~2 회로 감지 |
| 수명 | 코인셀 기준 수년(하루 수십 회 조작 가정) |
| 안전 | 상용전원 절연 불필요(전원 미연결). 접점은 무전위(dry) 연결만 |

> 중요: 이 노드는 **벽스위치의 220V 배선에 직접 연결하지 않는다.** 기존 스위치를
> 무전위 접점(별도 저전압 신호선)으로 사용하거나, 스위치와 병렬로 저전압 감지선을
> 연결하는 방식이다. 만약 대상 벽스위치가 220V 를 직접 물고 있는 구조라면, 절연형
> 입력(옵토커플러/저전압 서브회로)이 필요하며 이는 별도 안전 검토 대상이다.
> 본 설계의 기본 가정은 **무전위 접점 입력**이다.

## 2. 블록 다이어그램

```
           ┌──────────────────────────────────────────┐
  배터리 ──┤ 배터리홀더 → (선택)LDO/DCDC → VDD           │
 CR2032    │                                            │
           │   ┌──────────────┐   2.4GHz   ┌─────────┐  │
   벽스위치─┤ ▶│  GPIO SENSE   │  nRF54L15 │ 매칭+안테나│  │
  (접점)   │   │  디바운스 R/C │◀────────▶ │(PCB/chip)│  │
           │   └──────────────┘           └─────────┘  │
           │   상태 LED(선택), 커미셔닝 버튼             │
           └──────────────────────────────────────────┘
```

## 3. 핵심 부품 선정 (BOM 개요)

| 지정 | 부품 | 비고 |
|------|------|------|
| U1 | **nRF54L15** (QFN) | Thread/802.15.4, 초저전력, 내장 DC/DC |
| 안테나 | 2.4GHz 칩 안테나 또는 PCB 인버티드-F | 매입박스 금속 환경 고려해 방사 효율 검토 |
| 정합 | π 매칭 네트워크 (L/C) | nRF54L15 레퍼런스 정합 값 사용 |
| BT1 | CR2032 홀더 (또는 2×AAA 홀더) | 폼팩터에 맞춰 선택 |
| C_dec | 100nF + 1µF + 4.7µF | 디커플링/DCDC |
| R_pull | 1~10MΩ | 접점 감지 풀업(누설 최소화용 고저항) |
| R/C 디바운스 | 100kΩ + 100nF | 접점 채터링 억제 |
| SW1 | 택트 스위치 | 커미셔닝/공장초기화 |
| LED1 | 저전류 LED (선택) | 상태 피드백(평소 소등) |
| J1 | 스크류/스프링 터미널 | 벽스위치 접점 연결 |

정확한 정합 값·풋프린트·안테나 튜닝은 nRF54L15 레퍼런스 디자인/데이터시트를 따른다.

## 4. 입력 회로 (dry-contact 감지)

- 벽스위치 접점 → GPIO(SENSE 지원 핀). 평소 고임피던스 유지.
- **유지형(maintained)**: 접점 열림/닫힘 = 논리 1/0. 상태 변화 엣지로 wake.
- **순간형(momentary)**: 누름 펄스 감지 → 토글 명령.
- 누설 최소화: 상시 풀업 대신 이벤트 순간에만 능동 바이어스하거나, 매우 큰 풀업(≥1MΩ).
- R/C 하드웨어 디바운스 + 펌웨어 디바운스(수십 ms) 병행.

## 5. 전력 예산 (개략)

가정: SSED, CSL period 500ms, 조작 30회/일.

| 상태 | 전류(개략) | 시간 비중 |
|------|-----------|-----------|
| 딥 슬립(RAM 보존, RTC) | ~1–2 µA | 대부분 |
| CSL 수신 wake | 짧은 라디오 on | 주기적 |
| 조작 시 CoAP 왕복(TX/RX) | 수 mA, 수십 ms | 30회/일 |

평균 전류는 슬립 누설과 CSL 수신 오버헤드가 지배. CR2032(≈220mAh) 기준 수년 목표가
현실적이며, 정확한 값은 CSL period·풀업 누설·안테나 효율에 따라 결정 → **실측 필수**.

절전 팁:
- CSL period 를 응답성이 허용하는 한 최대화.
- 상태 LED 는 커미셔닝 외 소등, 저전류 구동.
- 접점 풀업 누설을 nA 급으로 억제.

## 6. 기구 / 폼팩터

- 목표: 기존 이너릴레이 매입 모듈과 동일한 외형·고정 방식으로 매입박스에 삽입.
- 배터리 교체 접근성 고려(코인셀 홀더 방향), 또는 교체 주기가 매우 길면 밀봉형 검토.
- 금속 매입박스는 2.4GHz 방사에 불리 → 안테나 배치/방향, 필요 시 외부 안테나 옵션.
- 배선: 기존 스위치 접점선을 J1 에 연결. 220V 결선 금지 라벨 명시.

## 7. 개방 이슈 (설계 확정 필요)

- [ ] 대상 벽스위치가 무전위 접점인지 220V 직결인지 현장 조사 → 절연 입력 필요 여부 확정.
- [ ] 배터리 폼팩터(CR2032 vs AAA) 최종 결정: 수명 vs 크기.
- [ ] 안테나 형식(PCB vs 칩 vs 외부) 및 매입박스 방사 실측.
- [ ] 커미셔닝 UX(버튼 조합/타이밍) 확정.
