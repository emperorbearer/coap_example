# 전등 노드 하드웨어 설계 (멀티 MCU)

전등 노드는 상시 전원으로 동작하며 실제 등기구(램프)를 스위칭한다. 저전력 제약이
없으므로 Thread FTD/Router 로 항상 깨어 있고, 여러 MCU 플랫폼으로 이식 가능하도록
설계한다.

## 1. 설계 목표

| 항목 | 목표 |
|------|------|
| 전원 | 상시 상용전원(AC 100–240V) → 내부 저전압 |
| 무선 | Thread (802.15.4, 2.4GHz), 멀티 MCU |
| 출력 | 램프 on/off (릴레이 또는 SSR/TRIAC). 디밍은 선택 |
| Thread 역할 | FTD/Router (메시 라우팅 겸함) |
| 안전 | 상용전원 절연·연면/공간거리·퓨즈 등 안전규격 준수 필요 |

## 2. 지원 MCU 플랫폼

| 플랫폼 | 부품(예) | Zephyr 보드(예) | 비고 |
|--------|----------|-----------------|------|
| Nordic | nRF54L15 / nRF52840 | `nrf54l15dk`, `nrf52840dk` | 우선 지원 |
| Silicon Labs | MGM240 모듈(EFR32MG24) | `xg24_dk` | 모듈 형태로 인증 용이 |
| Espressif | ESP32-H2 | `esp32h2_devkitm` | 802.15.4 내장 |
| Espressif | ESP32-C6 | `esp32c6_devkitc` | 802.15.4 + Wi-Fi |

> Zephyr 의 OpenThread 지원 성숙도는 플랫폼별로 차이가 있다. Nordic·Silabs 는 성숙,
> ESP32-H2/C6 는 Zephyr 상에서 지원되나 기능/안정성은 SDK 버전에 따라 확인 필요
> (ESP-IDF 대비). 플랫폼 추상화는 `firmware/light/boards/` 오버레이와
> DeviceTree alias 로 처리한다(§4).

## 3. 블록 다이어그램

```
 AC 100–240V ─┬─ 퓨즈 ─ AC/DC (절연형, 3.3V/5V) ─ VDD ─┐
              │                                        │
              │   ┌──────────────┐   2.4GHz  ┌───────┐ │
   램프 부하 ◀─┤ ▶│ 릴레이/SSR    │◀ MCU ────▶│안테나 │ │
   (조명)     │   │ 구동 + 절연   │ (Thread) └───────┘ │
              │   └──────────────┘   상태 LED, 버튼    │
              └───────────────────────────────────────┘
```

## 4. 플랫폼 추상화 (DeviceTree)

펌웨어는 보드 독립적으로 다음 alias/GPIO 를 참조한다. 각 보드 오버레이가 실제 핀에 매핑:

| alias | 용도 |
|-------|------|
| `light-relay` (`gpios`) | 램프 스위칭 출력(릴레이/SSR 게이트) |
| `sw0` / 버튼 | 로컬 수동 토글(선택) |
| `led0` | 상태 표시 |
| (옵션) `light-dim` (PWM) | 디밍 출력 |

→ `firmware/light/boards/<board>.overlay` 에서 정의. 코드에서는
`DT_ALIAS(light_relay)` 만 참조하므로 MCU 가 바뀌어도 앱 로직은 동일.

## 5. 출력단 설계

- **on/off 기본**: 기계식 릴레이(가청 클릭, 저비용) 또는 SSR(무음, 수명↑).
  릴레이 코일은 트랜지스터 + 플라이백 다이오드로 구동, MCU 와 절연 권장.
- **디밍(선택)**: 위상제어 TRIAC(누설/역률 주의) 또는 0–10V/PWM 조광 드라이버 연동.
  디밍 지원 시 상태 객체에 `bri` 필드 사용(`docs/coap-resource-model.md`).
- **부하 정격**: 대상 램프의 전류/서지(특히 LED 드라이버 인러시) 고려해 릴레이/SSR 정격 선정.

## 6. 안전 (상용전원)

- 1차/2차 **절연**(AC/DC, 릴레이 접점, 옵토 게이트) 확보.
- **퓨즈**/오버커런트 보호, 서지 대응(MOV/TVS).
- 연면·공간거리, PCB 슬롯, 인증(전자파/안전) 요건 준수.
- 접지·차폐와 2.4GHz 안테나 배치 상충 주의.

## 7. BOM 개요 (플랫폼 공통 + 가변)

| 지정 | 부품 | 비고 |
|------|------|------|
| U1 | MCU/모듈 (플랫폼별) | nRF54L15 / EFR32MG24(MGM240) / ESP32-H2 / ESP32-C6 |
| PSU | 절연형 AC/DC 모듈 | 3.3V(또는 5V→3.3V LDO), 대기전력 낮은 것 |
| K1 | 릴레이 또는 SSR | 부하 정격에 맞춰 |
| Q1/D1 | 릴레이 구동 TR + 플라이백 D | SSR 사용 시 옵토 게이트 |
| 안테나 | 칩/PCB/모듈 내장 | 모듈(MGM240)은 내장 옵션 |
| 보호 | 퓨즈, MOV/TVS | 안전 필수 |
| LED1, SW1 | 상태 LED, 버튼 | 로컬 토글/커미셔닝 |
