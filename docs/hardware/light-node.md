# 전등 노드 하드웨어 설계 (모듈러: 컨트롤러 + LED 보드)

전등 노드는 **KC 인증 SMPS**가 상용전원(AC)을 저전압 DC 로 변환해 공급하고, 그 DC 로
**CW/WW(쿨/웜 화이트) LED 를 색온도·디밍 구동**하는 **튜너블 화이트** 구성이다(풀컬러
RGB 는 사용하지 않음). 물리적으로는 열 영역(LED)과 RF/로직 영역(MCU)이 상충하므로
**모듈러(다중 보드)** 로 구성하는 것을 권장한다(§3). 상시 전원이므로 Thread FTD/Router 로
항상 깨어 있다.

## 1. 설계 목표

| 항목 | 목표 |
|------|------|
| 전원 | **KC 인증 SMPS**(AC 100–240V → DC). 메인라인 직결 회피 |
| 물리 구성 | **모듈러**: 컨트롤러 보드(FR4) + LED 보드(알루미늄) + SMPS 모듈 |
| 무선 | Thread (802.15.4, 2.4GHz), 멀티 MCU. **사전인증 모듈** 권장 |
| 광원 | CW/WW(쿨/웜) 화이트 LED 직접 구동 (릴레이/램프 아님) |
| 기능 | on/off + **디밍** + **색온도(CCT) 조절** (RGB 색상 없음) |
| Thread 역할 | FTD/Router (메시 라우팅 겸함) |

## 2. 전원 아키텍처 (핵심 변경)

```
 AC 100–240V ──▶ [ KC 인증 SMPS 모듈 ] ──▶ DC 레일(예: 12V/24V + 3.3V) ──▶ 커스텀 LED+MCU PCB
                 (1차/2차 절연·인증 포함)                                   (저전압만 취급)
```

- **안전/인증 분리**: 상용전원 절연·연면거리·인증 부담을 검증된 **KC 인증 SMPS 모듈**에
  위임한다. 커스텀 PCB 는 **저전압 DC 만** 취급하므로 설계·인증 리스크가 크게 준다.
- **DC 레일**: SMPS 출력(예: 12/24V, 또는 20~60V 범위)을 그대로 **LED 채널 CC 드라이버**
  입력으로 쓰고, MCU 전원용 **3.3V 는 온보드 벅**으로 강압한다. SMPS 전압이 넓거나 높으면
  두 경로 모두 이를 수용해야 한다(→ §5.4: 채널은 스위칭 벅 CC 드라이버, 3.3V 는
  와이드-Vin 벅).
- **전력 정격**: LED 총 소비전력 + 여유를 SMPS 정격으로 선정. 대기전력 낮은 모듈 선호.

### 2.1 전력 개산 (안방 예시)

가정: 안방 ~13–16 m²(4–5평), 목표 조도 100–150 lux, 백색 시스템 효율 ~100 lm/W,
드라이버 효율 ~88%. (등기구·확산판·목표조도에 따라 달라지는 **개략치**)

- 필요 광량 = 조도 × 면적 / 이용률(~0.7) → **약 1,900–3,400 lm** (안방 메인등 급).

| 모드 | 상태 | 전력(개략) |
|------|------|-----------|
| 백색 풀(일상) | 2,000–3,500 lm | **~20–40 W** (대표 ~25–35 W) |
| 디밍/무드 | 밝기 낮춤 | 수 W–15 W |
| 웜 색온도(디밍) | 보통 낮은 밝기 | ~수 W–20 W |
| **설계 피크**(전 채널 최대) | 최악 | **~40–60 W** |
| 대기(소등) | MCU 상시(FTD) + SMPS 무부하 | ~0.3–0.5 W |

- **SMPS 사이징**: "설계 피크"로 선정 → **~60 W(여유 포함, 예 24V/2.5A)** 무난. 동시 최대를
  안 쓰면 40–50W 도 가능하나 여유 권장.
- **대기전력**: 상시 전원 + 상시 라우터라 **무부하 대기 낮은 모듈** 필수(0.4W×24h≈3.5kWh/년).
- **에너지 감**: 30W × 4h/일 ≈ 44 kWh/년 ≈ 6–7천원/년(누진 제외 개략).
- **LED 개수 감**: 24V 백색 6–7직렬, 30W 백색 = 24V에서 ~1.25A. 0.5W급 ~60개 / 1W급 ~30개
  / COB 1개 등 사용 LED 사양에 따라.

## 3. 물리 보드 구성 (모듈러 권장)

**권장: MCU를 알루미늄 PCB에 직접 납땜하지 말고, 열/RF 영역을 분리한 다중 보드로
구성한다.**

```
 [ KC 인증 SMPS 모듈 ] ──DC──┬──▶ [ 컨트롤러 보드 (FR4) ]
   AC→DC, 절연·인증          │      - MCU/사전인증 라디오 모듈
                            │      - 그라운드 플레인 + 안테나 keep-out
                            │      - PWM 로직, 3.3V 벅/LDO
                            │            │
                            │       PWM R/G/B/W (+DC)  ← 커넥터/FFC
                            │            ▼
                            └──▶ [ LED 보드 (알루미늄 MCPCB) ]
                                   - CW/WW LED + 채널 정전류 드라이버
                                   - 방열(알루미늄 기판)
```

### 왜 "알루미늄에 MCU 직접 납땜"은 피하나

- **RF 치명적**: 2.4GHz 안테나는 **그라운드 플레인과 금속 keep-out**이 필요하다.
  알루미늄 기판(넓은 금속면)이 안테나 근처에 있으면 **디튜닝·흡수**로 방사 성능이
  무너진다. 라디오를 알루미늄 위에 두는 것은 근본적으로 불리.
- **배선 제약**: 알루미늄 MCPCB 는 보통 **단층**(또는 고가 2층)이라 MCU 의 다중 신호
  (PWM·SPI·크리스털·디커플링)를 라우팅하기 어렵고 **레퍼런스 그라운드 확보가 곤란**.
- **열 간섭**: LED 발열이 MCU/크리스털/라디오로 유입되면 안정성·수명에 불리.

### 권장 모듈러 구성 (3블록)

1. **LED 보드 = 알루미늄 MCPCB**: CW/WW LED + 채널 정전류 드라이버. 알루미늄으로 **방열**.
2. **컨트롤러 보드 = FR4**: MCU + PWM 로직 + 3.3V 전원. **사전인증(KC/FCC/CE) 라디오
   모듈** 실장을 강력 권장 → RF 레이아웃·인증 부담 대폭 감소, 플랫폼 교체 용이.
   제대로 된 그라운드 플레인 + 안테나 keep-out 확보.
3. **SMPS = KC 인증 모듈**(별도). AC 절연·인증을 위임.
4. **인터커넥트**: 컨트롤러↔LED 보드는 **커넥터/FFC**로 연결하고 **PWM 채널 신호 + DC**를
   전달. PWM 은 저속이라 신호무결성 이슈가 적으나 DC 전류 정격은 충분히.

### 단일 알루미늄 보드가 그나마 가능한 경우

**외장 안테나(u.FL/IPEX)** + **사전인증 모듈** + 낮은 핀수를 모두 만족할 때만 제한적으로
고려. 단층 라우팅·열 간섭 제약이 남아 일반적으로 권장하지 않는다.

## 4. 지원 MCU 플랫폼 (컨트롤러 보드에 실장)

| 플랫폼 | 부품(예) | Zephyr 보드(프로토타입) | 색온도/디밍 |
|--------|----------|-------------------------|-------------|
| Nordic | nRF54L15 / nRF52840 | `nrf54l15dk` | PWM CW/WW (레퍼런스) |
| Espressif | ESP32-H2 / ESP32-C6 | `esp32h2_devkitm` / `esp32c6_devkitc` | LEDC PWM CW/WW |
| Silicon Labs | MGM240 / EFR32MG24 | `xg24_dk` | 기본 on/off, PWM 는 SDK 확인 후 |

> **사전인증 모듈** 형태(예: MGM240 모듈, ESP32-H2/C6 모듈, nRF54L 기반 모듈)를 쓰면
> 컨트롤러 보드에서 라디오 인증을 재사용하고 **모듈만 교체**해 플랫폼을 바꿀 수 있다.
> 프로토타입은 각 DK 로 검증하고, 양산은 선택한 모듈을 컨트롤러 보드에 실장한다.
> 펌웨어는 DT alias(`pwm-cw`/`pwm-ww` 또는 `light-relay`)만 참조하므로
> 백엔드(PWM/릴레이)는 보드 오버레이로 결정된다. (`firmware/light/boards/*`)

## 5. LED 구동단 (색온도 + 디밍, 튜너블 화이트)

색온도와 디밍은 **CW/WW 2채널 + 채널별 정전류(CC) + PWM 디밍** 으로 구현한다. LED 와
채널 드라이버는 **LED 보드(알루미늄 MCPCB)** 에 두어 방열하고, PWM 제어 신호만 컨트롤러
보드에서 받는다.

### 5.1 원리 (색온도 = 비율, 디밍 = 스케일)

- **색온도**: 쿨화이트(CW)와 웜화이트(WW) 두 채널의 **밝기 비율**로 결정. → 상태의 `ct`.
  펌웨어가 `ct`(mireds)를 CW/WW 듀티로 변환(`cw+ww` 합이 일정해 밝기 유지).
- **디밍(밝기)**: 두 채널에 공통 **마스터 밝기**를 곱해 스케일. → 상태의 `bri`.
- 최종 출력 = `채널값(0..255) × bri(1..254) / 254`
  (`firmware/light/src/light_state.c`).

### 5.2 왜 PWM 디밍인가

- **정전류는 고정, 밝기는 PWM으로 자름** → 밝기를 낮춰도 **색점이 유지**된다.
- 전류 진폭을 줄이는 **아날로그 디밍은 색온도가 틀어져** 정확도가 나빠진다.
- PWM 주파수는 **플리커·가청소음 회피 위해 충분히 높게**(수 kHz↑, 또는 CC 드라이버의
  DIM/EN 입력 사양). 저휘도 부드러움을 위해 **감마 보정 LUT**를 추가.

### 5.3 채널 회로 (택1)

| 방식 | 특징 |
|------|------|
| 로우사이드 **N-MOSFET + 리니어 CC/저항** | 저비용. **발열 큼** — 레일 전압이 스트링 Vf보다 높을수록 손실 `(Vrail−Vf)×I`. 고전압/가변 레일엔 부적합 |
| **채널별 스위칭 정전류 드라이버 IC**(벅형, PWM/EN 디밍) | **권장**. 효율↑, **넓은 입력전압 수용**, PWM 핀으로 디밍 |

- **채널 구성**: CW / WW **2채널**. 각 채널 = 화이트 LED 스트링 + 정전류원.
- **색온도 범위**: 예 2700K(웜)–6500K(쿨). CW/WW 각각의 색온도 LED 를 선정.
- **LED 선정**: CW·WW 화이트 LED, Vf≈3.0V 내외 → 채널별 직렬 스트링 설계.

### 5.4 SMPS 레일 전압 (예: 20–60V DC 대응)

SMPS 출력이 **20~60V 로 다양(또는 높음)해도 괜찮은지는 드라이버 방식이 좌우**한다.

- ✅ **채널별 스위칭 벅 CC 드라이버**: 입력전압이 넓어도 전류를 일정하게 regulation.
  드라이버 IC 가 **≥60V 입력 정격**이고 LED 스트링 Vf 가 **최소 입력(20V)보다 벅 헤드룸
  만큼 낮으면** 20~60V 어디서든 동작 → **가변/다양 전압 OK**.
- ❌ **리니어 CC/저항**: 손실 `(Vrail−Vf)×I`. 60V 레일에 12V 스트링이면 대부분을 열로
  버림 → 고전압/가변 레일엔 사용 불가.
- **3.3V 로직 레일**: 입력이 최대 60V 면 온보드 3.3V 벅도 **와이드-Vin(≥60V 정격)** 부품
  필요(흔한 ≤40V 벅 불가).
- **스트링 설계 팁**: 스트링 Vf 를 최소 전압(20V)보다 낮게(예 ≤15–18V) 잡아 벅이 항상
  강압하도록. 고전압일수록 직렬 LED 를 더 넣어 효율↑.
- **안전**: 60V DC 는 SELV 경계 부근 — 여전히 저전압이나 연면/취급 유의.
- 펌웨어는 전압과 무관(PWM만) → **드라이버·전원 부품 선정 문제**.

### 5.5 LED 선정 · 배치 (튜너블 화이트)

**LED 종류 (CW/WW 화이트)**

| 종류 | 혼합 | 비고 |
|------|------|------|
| 개별 CW·WW 화이트 LED(2종) | 좋음 | **권장 기본**. 각 색온도 LED 를 채널 스트링으로 |
| **2-in-1 CW/WW 패키지**(듀얼 화이트) | 매우 좋음 | 두 다이가 근접 → 색온도 혼합 균일 |
| **튜너블 화이트 COB**(CW/WW 한 기판) | 매우 좋음 | 고출력·균일면, 방열 중요 |

- 고CRI 화이트 LED 를 선정(주광용). CW≈5000–6500K, WW≈2700–3000K 조합이 일반적.
- 풀컬러 RGB 는 사용하지 않으므로 구성이 단순(2채널)하고 효율·CRI 가 좋다.

**배치 원칙 (균일한 색온도·조도)**

1. **CW/WW 인터리브**: CW 와 WW 를 몰지 말고 교대로 배열해 국소 색온도 편차를 줄인다.
   듀얼 화이트 패키지면 패키지 단위로 균등 배열(격자/링).
2. **근접 배치/디퓨저**: CW·WW 를 가까이 두고 확산판(오팔/프로스트)을 피치 이상 띄워
   색온도를 블렌드(면 전체가 균일한 색으로 보이도록).
3. **대칭 배열**: 원형 등기구는 링/동심원, 패널은 격자로 균등 배치.
4. **방열 배치**: 알루미늄 기판 전체로 발열 분산, 뜨거운 부분은 가장자리·전자부에서 이격,
   LED 패드 아래 구리 채움/서멀 비아.
5. **직렬 스트링 배선**: 한 채널(CW 또는 WW)은 **직렬**로 묶어 전류를 일치시키되, 배선을
   보드 전반으로 **스네이크**해 CW/WW 가 공간적으로 고르게 섞이도록.

**직렬 수 ↔ 레일 전압 (§5.4 연동)**

채널당 직렬 LED 수가 스트링 Vf 를 정하고, 이는 SMPS 레일과 벅 헤드룸으로 제한된다.
예) 화이트 6직렬 × 3.0V ≈ 18V → 24V 레일에서 벅 CC 로 구동 가능. 레일이 높을수록
직렬을 더 넣어(스트링↑) 병렬 수를 줄이면 배선·효율이 좋아진다. 병렬 스트링을 쓸 경우
Vf 매칭 또는 스트링별 CC 로 **전류 밸런싱** 필요.

**캘리브레이션**

유닛 간 색온도 편차를 줄이려면 **타이트한 컬러/플럭스 빈** 선정 + 필요 시 펌웨어
색온도 보정(CW/WW 매핑 조정, `light_state.c:drive_output()`).

## 6. 방열/EMC

- **LED 보드(알루미늄)**: LED·드라이버 발열을 알루미늄 기판으로 방열, 등기구 방열 구조
  연계. 서멀 인터페이스(패드/그리스)로 케이스 방열 연결.
- **컨트롤러 보드(FR4)**: 라디오는 LED 열원에서 이격. 그라운드 플레인 + 안테나 keep-out.
- **인터커넥트/EMC**: 컨트롤러↔LED 보드 배선의 PWM 스위칭 노이즈 및 SMPS 배선의 2.4GHz
  간섭 대책(배선 길이·경로, 필터, 접지). 안테나는 금속 방열구조/전원부와 이격.

## 8. 개방 이슈

- [ ] 보드 분할 확정(컨트롤러 FR4 / LED 알루미늄) 및 커넥터·핀 정의(PWM+DC).

      레일이 스트링 Vf 에 근접할 때만.
