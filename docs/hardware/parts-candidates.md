# 부품 후보표 (전등 노드)

전등 노드(모듈러: 컨트롤러 FR4 + LED 알루미늄 + SMPS, RGBW 색상+디밍, 20–60V 레일,
안방 ~60W)를 위한 **대표 부품 후보**다.

> ⚠️ 아래는 방향 잡기용 **대표 후보**다. 정확한 전기 사양·핀·**KC/FCC/CE 인증**·재고·단종은
> 반드시 **데이터시트/유통사**에서 확인하고, 최종 값은 설계 조건(레일 전압, 스트링 Vf,
> 채널 전류, 목표 광량)에 맞춰 재선정한다.

## 1. RGBW / RGBWW LED

| 후보(계열) | 유형 | 특징 |
|-----------|------|------|
| ams OSRAM **OSLON Square/SSL**(색상별 + 화이트) | 개별 색 고출력 | 고품질·고출력, 채널 스트링 구성 |
| Lumileds **LUXEON C Color**(LXZ1) + LUXEON 화이트 | 개별 색 emitter(~1–2W) | 색연출 luminaire 표준 |
| Nichia **NCS/NSSM** 색상 + **NFSW** 화이트 | 개별/멀티칩 | 고CRI 화이트 조합 |
| **5050/5060 RGBW 4-in-1 SMD**(Everlight/Cree/Dominant) | 멀티다이 SMD | 저비용·믹싱 양호(권장 기본) |
| Citizen/Bridgelux **튜너블 화이트 COB** (+RGB 별도) | COB | 고출력·균일면 |

- 색 혼합 우선 → **멀티다이 SMD** 또는 **COB**(§5.5). 화이트는 **전용 다이** 필수(CRI).
- 튜너블 화이트 원하면 **CW+WW(RGBWW, 5채널)**.

## 2. 채널 정전류(CC) 스위칭 드라이버 IC (20–60V 입력, PWM 디밍)

| 후보 | Vin(개략) | 채널 전류 | 디밍 | 통합 |
|------|-----------|-----------|------|------|
| TI **TPS92515HV** | ~4.5–65V | ~1.2A | 아날로그+PWM | FET 내장 |
| TI **LM3409HV** | ~6–75V | 외부 FET(고전류) | PWM | 컨트롤러 |
| Diodes **AL8862** | ~5–60V | ~1.5A | PWM | 내장 |
| onsemi **NCL30160** | ~6.3–60V | ~1A | PWM | 내장 |
| MPS **MP24894** | ~5–55V | ~1.5A | PWM/아날로그 | 내장 |

- 채널당 1개(R/G/B/W). **≥60V 입력 정격** + LED 스트링 Vf < 최소 레일(헤드룸) 확인(§5.4).
- 고전류가 필요하면 외부 FET 컨트롤러(LM3409HV), 간단·집적이면 내장형(AL8862/NCL30160).

## 3. 3.3V 로직용 와이드-Vin 벅 (SMPS 20–60V 수용)

| 후보 | 사양(개략) | 비고 |
|------|-----------|------|
| TI **LM5165** | ~3–65V, 150mA, **초저 Iq(~10µA)** | 상시 전원 대기 유리(MCU만) |
| TI **TPS54160** | ~3.5–60V, 1.5A | 여유 전류 |
| TI **LMR16030** | ~4.3–60V, 3A | 디스플레이/여유 부하 |
| MPS **MP9486A** | ~4–100V, 1A | 고전압 여유 |

- MCU만이면 저Iq 소전류(LM5165). 디스플레이/부가부하가 있으면 전류 여유(TPS54160↑).

## 4. KC 인증 SMPS 모듈 (~60W, 24V, 정전압)

| 후보 | 사양 | 비고 |
|------|------|------|
| Mean Well **LRS-75-24** | 75W/24V, 오픈프레임 | 내장형, KC 有 |
| Mean Well **LPV-60-24** | 60W/24V/2.5A, IP67 | 방수형 |
| Mean Well **HLG-60H-24** | 60W/24V, CV+CC | 조명용, KC 有 |
| 국내(Moso/Inventronics/Fine 등) 24V 60–75W | CV | KC 확인 후 |

- 채널에서 CC 를 하므로 SMPS 는 **정전압(CV)** 이면 충분(LRS/LPV). **무부하 대기 낮은** 모델.
- **설계 피크(~40–60W)** 기준으로 60–75W 여유 선정(§2.1).

## 5. 사전인증 라디오 모듈 (컨트롤러 보드 실장)

| 후보 | 플랫폼 | 비고 |
|------|--------|------|
| Silabs **MGM240P/MGM240S** | EFR32MG24, Thread/Matter | 모듈=사전인증, 바로 실장 |
| Espressif **ESP32-H2-MINI-1** | 802.15.4/Thread | 저가, 사전인증 |
| Espressif **ESP32-C6-MINI-1/WROOM-1** | 802.15.4+Wi-Fi | 저가, 사전인증 |
| Nordic **nRF54L 기반 모듈**(Raytac/Fanstel) | nRF54L15 | 신제품 → 출시/인증 확인 |
| (대체) Raytac **MDBT53**(nRF5340)/**MDBT50Q**(nRF52840) | Nordic | 성숙 모듈 |

- **모듈 사용 시** 라디오 인증을 재사용 → 인증·RF 부담↓, 모듈 교체로 플랫폼 전환(§3).
- 베어 MCU 직접 실장은 자체 RF 인증 필요.

## 6. 보드간 커넥터 (컨트롤러 ↔ LED)

| 후보 | 용도 |
|------|------|
| JST **XH/VH** | DC 전원(전류 정격 여유) |
| JST **PH/SH** | PWM 신호(R/G/B/W) |
| Hirose **DF13/DF11**, Molex **Pico-Blade** | 보드간 범용 |
| FFC + Hirose **FH** 시리즈 | 박형 기구 |

- PWM 은 저속이라 SI 이슈 적음. **DC 전류 정격**과 접점 신뢰성 위주로 선정.

## 7. 조합 예시 (안방 ~60W, 24V 레일, RGBW)

| 블록 | 선정(예) |
|------|----------|
| SMPS | Mean Well **LRS-75-24** (KC, CV) |
| 채널 드라이버 | **TPS92515HV** × 4 (R/G/B/W) |
| 3.3V 로직 | **LM5165** (저Iq) |
| 라디오 | **MGM240P** 모듈 (또는 ESP32-H2-MINI-1) |
| LED | OSLON 색상 + 화이트, 또는 5050 RGBW 4-in-1 |
| 커넥터 | JST **XH**(전원) + **PH**(PWM) |

> 이 조합은 출발점이다. 스트링 Vf/전류·목표 광량·기구 두께·비용에 맞춰 각 항목을 확정하고
> 데이터시트로 검증한다.
