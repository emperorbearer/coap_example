# 패널 스위치 하드웨어 설계 (버튼 + 로터리 엔코더)

기존 온오프 이너 스위치와 별개로, **스위치 커버 크기의 PCB**에 여러 버튼과 로터리
엔코더를 배치해 전등을 다채롭게 제어하는 **배터리 구동 무선 컨트롤러**다. Thread SSED
로 동작하며 CoAP 로 바인딩된 전등의 on/off·밝기·색상·색온도를 조작한다.

## 1. 설계 목표

| 항목 | 목표 |
|------|------|
| 폼팩터 | 표준 스위치 커버 크기 PCB (벽 스위치 커버에 부착/일체형) |
| 전원 | **리튬이온 충전지 + nPM1300 PMIC**(충전 + 다중 레일 + 퓨얼게이지) |
| 충전 | **USB-C** 입력(nPM1300 VBUS) |
| 무선 | Thread (802.15.4, 2.4GHz), nRF54L15 |
| 입력 | 버튼 4개 + 로터리 엔코더(푸시 포함) |
| 수명 | 1회 충전으로 수개월~수년(입력 시에만 wake), 재충전식 |

이너 스위치(코인셀 1차 전지)와 달리 패널(월스위치) 타입은 **충전식 리튬이온**을 쓰며,
전원 관리를 **nPM1300** PMIC 에 맡긴다(USB-C 충전, 퓨얼게이지, I2C 제어). 초저전력
SSED 라디오 전략은 이너 스위치와 동일하게 공유한다(라디오 절전은 `switch-node.md`
§5 참조). 전원 아키텍처는 아래 §2 참조.

## 2. 전원 아키텍처 (nPM1300 + 리튬이온 + USB-C)

```
 USB-C ─▶ VBUS ─┐
                ▼
 Li-ion 셀 ─▶ [ nPM1300 PMIC ] ─┬─ BUCK1 → 3.3V ─▶ nRF54L15 VDD
 (VBAT,보호셀)  │                ├─ BUCK2 → (선택)레일 ─▶ 백라이트/센서
  NTC ─────────▶│(배터리 온도)    ├─ LDO/LOADSW → (선택)주변 급전
                │ - USB-C 충전기(JEITA)                    │  버튼×4 / 엔코더 A·B·푸시
                │ - 퓨얼게이지용 측정(VBAT/전류/온도)        │  (GPIO/QDEC, SENSE wake)
                │ - Ship/Hibernate 저전력 모드              │  (선택)상태 LED/백라이트
                └── I2C(TWI) ◀──▶ nRF54L15 제어             └── 2.4GHz 안테나
```

- **nPM1300 역할**: 단일 셀 리튬이온 **USB-C 충전기(JEITA 온도 보상)** + **2×벅 +
  LDO/로드스위치** + **연료게이지 측정** + **GPIO/이벤트**를 통합. **I2C(TWI)** 로
  nRF54L15 가 제어·모니터링한다. Ship/Hibernate 모드로 대기 소비를 극소화한다.
- **충전 경로(USB-C)**: USB-C 커넥터 → nPM1300 **VBUS** 입력. USB 포트 감지·입력전류
  제한을 PMIC 가 처리하고, 충전 중에도 power-path 로 부하에 급전한다.
- **레일 구성**: BUCK1 을 3.3V nRF54L15 메인 레일로. 백라이트/추가 센서가 있으면 BUCK2
  또는 LDO/로드스위치로 분리 급전하여 필요 시에만 켠다(누설 절감).
- **셀 보호/온도**: 리튬이온 셀은 보호회로 내장 셀(또는 외부 보호 IC)을 사용하고, **NTC
  서미스터**를 셀에 부착해 nPM1300 의 배터리 온도 감지(JEITA)로 안전 충전을 보장한다.
- **펌웨어**: Zephyr 의 **nPM1300 드라이버 스택**으로 제어한다 — MFD(`nordic,npm1300`),
  `regulator`(BUCK/LDO), `charger`(`npm1300_charger`), `gpio`. **배터리 잔량**은
  nPM1300 측정값(VBAT/전류/온도)을 **nRF Fuel Gauge 라이브러리**에 입력해 SoC(%)를
  산출한다. 충전 상태/USB 연결 이벤트는 드라이버 콜백으로 수신.

## 3. 입력부

- **버튼 4개**: 택트 스위치. 각 GPIO 는 SENSE 지원 핀으로 deep sleep wake.
  펌웨어에서 `gpio-keys` → 입력 키코드(KEY_0..3)로 매핑.
- **로터리 엔코더**: 증분형(quadrature) A/B + 푸시. `gpio-qdec` 로 회전량을
  상대 이벤트(INPUT_REL_WHEEL)로 처리, 푸시는 별도 버튼(KEY_ENTER).
  - 회전: 활성 모드 값 조절(밝기/색온도).
  - 푸시: on/off 토글.
- **디바운스**: 버튼 R/C + 펌웨어 디바운스. 엔코더는 QDEC 샘플링/필터로 처리.
- **누설 최소화**: 풀업은 고저항 또는 이벤트 시에만 능동화(배터리 수명).

## 4. 사용자 피드백 (선택)

- 상태 LED 또는 버튼 백라이트로 조작 확인. 평소 소등, 조작 시 짧게 점등(저전류).
- 엔코더 모드(밝기/색온도) 표시가 필요하면 소형 LED 2~3개 또는 단색 인디케이터.

## 5. 기구 / 폼팩터

- 표준 스위치 커버 치수에 맞춘 PCB. 버튼·엔코더 노브가 커버 전면으로 노출.
- **충전 접근성(USB-C)**: USB-C 커넥터를 커버 측면/하단에 노출 배치. 리튬이온 셀은
  고정식(재충전)으로 두고 교체는 서비스 시에만. 커넥터 개구부 방수/먼지 대책 고려.
- 리튬이온 셀 두께가 커버 깊이를 좌우 → 각형/파우치 소형 셀 선정과 기구 두께 병행 설계.
- 2.4GHz 안테나는 금속/손 접촉 영향 최소화 위치에 배치.

## 6. BOM 개요

| 지정 | 부품 | 비고 |
|------|------|------|
| U1 | nRF54L15 | Thread SSED |
| U2 | **nPM1300** PMIC | USB-C 충전기 + 2×벅 + LDO/로드스위치 + 퓨얼게이지 측정, I2C 제어 |
| BT1 | **리튬이온 셀(보호회로 포함)** | 각형/파우치 소형, 커버 두께에 맞춤 |
| RT1 | **NTC 서미스터** | 셀 부착, nPM1300 배터리 온도(JEITA) |
| J_usb | **USB-C 커넥터** | nPM1300 VBUS 충전 입력 |
| D_esd | USB VBUS/데이터 ESD 보호 | USB-C 포트 보호 |
| I2C | SDA/SCL 풀업 저항 | nRF54L15 ↔ nPM1300 제어 버스 |
| SW1–4 | 택트 스위치 | 액션 버튼 |
| ENC1 | 증분형 로터리 엔코더(푸시형) | A/B + 푸시 |
| R_cfg | nPM1300 설정 저항(필요 시) | 데이터시트 스트랩 |
| 안테나/정합 | 칩/PCB 안테나 + π 매칭 | nRF54L15 레퍼런스 |
| LED(선택) | 저전류 LED/백라이트 | nPM1300 GPIO 로 충전상태 표시 가능 |
| C_dec 등 | 디커플링/벅 입출력 커패시터 | BUCK1/BUCK2 인덕터·커패시터 포함 |

> 배터리 잔량은 nPM1300 측정값(VBAT/전류/온도)을 **nRF Fuel Gauge 라이브러리**에
> 입력해 SoC(%)로 산출한다(별도 ADC 분압 불필요).
