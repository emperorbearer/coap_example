# 패널 스위치 하드웨어 설계 (버튼 + 로터리 엔코더)

기존 온오프 이너 스위치와 별개로, **스위치 커버 크기의 PCB**에 여러 버튼과 로터리
엔코더를 배치해 전등을 다채롭게 제어하는 **배터리 구동 무선 컨트롤러**다. Thread SSED
로 동작하며 CoAP 로 바인딩된 전등의 on/off·밝기·색상·색온도를 조작한다.

## 1. 설계 목표

| 항목 | 목표 |
|------|------|
| 폼팩터 | 표준 스위치 커버 크기 PCB (벽 스위치 커버에 부착/일체형) |
| 전원 | 배터리 (CR2032 또는 CR2450, 필요 시 2×AAA) |
| 무선 | Thread (802.15.4, 2.4GHz), nRF54L15 |
| 입력 | 버튼 4개 + 로터리 엔코더(푸시 포함) |
| 수명 | 코인셀 기준 수년(입력 시에만 wake) |

이너 스위치와 동일한 초저전력 SSED 전략을 공유한다(전력 설계는
`switch-node.md` §5 참조). 여기서는 입력부 구성에 집중한다.

## 2. 블록 다이어그램

```
 ┌───────────────────────────────────────────────┐
 │ 배터리(CR2450) → (선택)DCDC → VDD               │
 │                                                 │
 │  버튼×4 ─┐                        ┌─ 2.4GHz     │
 │  엔코더 A/B ─▶ GPIO/QDEC  nRF54L15 │  안테나     │
 │  엔코더 푸시 ─┘  (INPUT/SENSE)     └───────────  │
 │  (선택) 상태 LED / 백라이트                      │
 └───────────────────────────────────────────────┘
```

## 3. 입력부

- **버튼 4개**: 택트 스위치. 각 GPIO 는 SENSE 지원 핀으로 deep sleep wake.
  펌웨어에서 `gpio-keys` → 입력 키코드(KEY_0..3)로 매핑.
- **로터리 엔코더**: 증분형(quadrature) A/B + 푸시. `gpio-qdec` 로 회전량을
  상대 이벤트(INPUT_REL_WHEEL)로 처리, 푸시는 별도 버튼(KEY_ENTER).
  - 회전: 활성 모드 값 조절(밝기/색온도).
  - 푸시: on/off 토글.
- **디바운스**: 버튼 R/C + 펌웨어 디바운스. 엔코더는 QDEC 샘플링/필터로 처리.
- **누설 최소화**: 풀업은 고저항 또는 이벤트 시에만 능동화(배터리 수명).

## 4. 사용자 피드백 (선택)

- 상태 LED 또는 버튼 백라이트로 조작 확인. 평소 소등, 조작 시 짧게 점등(저전류).
- 엔코더 모드(밝기/색온도) 표시가 필요하면 소형 LED 2~3개 또는 단색 인디케이터.

## 5. 기구 / 폼팩터

- 표준 스위치 커버 치수에 맞춘 PCB. 버튼·엔코더 노브가 커버 전면으로 노출.
- 배터리 교체 접근성(코인셀 홀더 방향) 고려. 커버 탈착 구조와 연계.
- 2.4GHz 안테나는 금속/손 접촉 영향 최소화 위치에 배치.

## 6. BOM 개요

| 지정 | 부품 | 비고 |
|------|------|------|
| U1 | nRF54L15 | Thread SSED |
| SW1–4 | 택트 스위치 | 액션 버튼 |
| ENC1 | 증분형 로터리 엔코더(푸시형) | A/B + 푸시 |
| BT1 | CR2450/CR2032 홀더 | 용량 여유 위해 CR2450 권장 |
| 안테나/정합 | 칩/PCB 안테나 + π 매칭 | nRF54L15 레퍼런스 |
| LED(선택) | 저전류 LED/백라이트 | 피드백 |
| C_dec 등 | 디커플링 | — |
