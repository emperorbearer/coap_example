# 패널 스위치 하드웨어 설계 (버튼 + 로터리 엔코더)

기존 온오프 이너 스위치와 별개로, **스위치 커버 크기의 PCB**에 여러 버튼과 로터리
엔코더를 배치해 전등을 다채롭게 제어하는 **배터리 구동 무선 컨트롤러**다. Thread SSED
로 동작하며 CoAP 로 바인딩된 전등의 on/off·밝기·색상·색온도를 조작한다.

## 1. 설계 목표

| 항목 | 목표 |
|------|------|
| 폼팩터 | 표준 스위치 커버 크기 PCB (벽 스위치 커버에 부착/일체형) |
| 전원 | **리튬이온 충전지 + nPM1100 PMIC**(충전 + 벅 레귤레이터) |
| 무선 | Thread (802.15.4, 2.4GHz), nRF54L15 |
| 입력 | 버튼 4개 + 로터리 엔코더(푸시 포함) |
| 수명 | 1회 충전으로 수개월~수년(입력 시에만 wake), 재충전식 |

이너 스위치(코인셀 1차 전지)와 달리 패널(월스위치) 타입은 **충전식 리튬이온**을 쓰며,
전원 관리를 **nPM1100** 저전력 PMIC 에 맡긴다. 초저전력 SSED 라디오 전략은 동일하게
공유한다(라디오 절전은 `switch-node.md` §5 참조). 전원 아키텍처는 아래 §2 참조.

## 2. 전원 아키텍처 (nPM1100 + 리튬이온)

```
 충전입력(USB-C 또는 충전접점) ─┐
                               ▼
 Li-ion 셀(보호회로 포함) ──▶ [ nPM1100 PMIC ] ──▶ VOUT(예 3.0/3.3V) ──▶ nRF54L15 VDD
   (VBAT)                      │ - Li-ion 충전기(CC/CV)                    │
                               │ - 고효율 벅 레귤레이터                     │  버튼×4 / 엔코더 A·B·푸시
                               │ - Ship/저Iq 모드                          │  (GPIO/QDEC, SENSE wake)
                               └── CHG 상태 핀 ─▶ (선택)MCU 표시            │  (선택)상태 LED/백라이트
                                                                           └── 2.4GHz 안테나
```

- **nPM1100 역할**: 단일 셀 리튬이온 **충전기(CC/CV)** + **고효율 벅**을 한 칩에 통합.
  I2C 없이 핀 스트랩으로 동작하고 정지전류(Iq)가 매우 낮아 SSED 배터리 설계에 적합하다.
  출력 전압은 핀 설정(예 1.8/2.1/2.7/3.0/3.3V), 충전 전류도 핀으로 설정한다.
- **충전 경로**: USB-C 입력 또는 커버 탈착 시 노출되는 **충전 접점(pogo)** 으로 충전.
  충전 중에도 부하 급전(power-path)은 nPM1100 이 처리한다.
- **셀 보호**: 리튬이온 셀은 **보호회로(과충전/과방전/과전류)** 내장 셀 또는 외부 보호 IC
  를 사용한다(안전 필수). 셀 폼팩터는 커버 두께에 맞춰 각형/파우치 소형 셀 검토.
- **펌웨어**: nPM1100 은 자율 동작(전용 드라이버 불필요). 충전 상태는 **CHG/ERR 상태 핀**
  을 MCU GPIO 로 읽어 표시 가능. **배터리 잔량**은 nPM1100 에 퓨얼게이지가 없으므로
  VBAT 을 MCU ADC(SAADC)로 측정해 추정한다.
  - 퓨얼게이지·다중 레일·I2C 제어가 필요하면 상위 칩(**nPM1300**)을 대안으로 검토
    (이 경우 Zephyr regulator/charger 드라이버로 제어).

## 3. 입력부

- **버튼 4개**: 택트 스위치. 각 GPIO 는 SENSE 지원 핀으로 deep sleep wake.
  펌웨어에서 `gpio-keys` → 입력 키코드(KEY_0..3)로 매핑.
- **로터리 엔코더**: 증분형(quadrature) A/B + 푸시. `gpio-qdec` 로 회전량을
  상대 이벤트(INPUT_REL_WHEEL)로 처리, 푸시는 별도 버튼(KEY_ENTER).
  - 회전: 활성 모드 값 조절(밝기/색온도).
  - 푸시: on/off 토글.
- **디바운스**: 버튼 R/C + 펌웨어 디바운스. 엔코더는 QDEC 샘플링/필터로 처리.
- **누설 최소화**: 풀업은 고저항 또는 이벤트 시에만 능동화(배터리 수명).

## 4. 사용자 피드백 (선택)

- 상태 LED 또는 버튼 백라이트로 조작 확인. 평소 소등, 조작 시 짧게 점등(저전류).
- 엔코더 모드(밝기/색온도) 표시가 필요하면 소형 LED 2~3개 또는 단색 인디케이터.

## 5. 기구 / 폼팩터

- 표준 스위치 커버 치수에 맞춘 PCB. 버튼·엔코더 노브가 커버 전면으로 노출.
- **충전 접근성**: USB-C 포트를 측면/하단에 두거나, 커버 탈착 시 노출되는 충전 접점 구성.
  리튬이온 셀은 고정식(재충전)으로 두고 교체는 서비스 시에만.
- 리튬이온 셀 두께가 커버 깊이를 좌우 → 각형/파우치 소형 셀 선정과 기구 두께 병행 설계.
- 2.4GHz 안테나는 금속/손 접촉 영향 최소화 위치에 배치.

## 6. BOM 개요

| 지정 | 부품 | 비고 |
|------|------|------|
| U1 | nRF54L15 | Thread SSED |
| U2 | **nPM1100** PMIC | Li-ion 충전기 + 고효율 벅, 저Iq, 핀 제어 |
| BT1 | **리튬이온 셀(보호회로 포함)** | 각형/파우치 소형, 커버 두께에 맞춤 |
| J_chg | USB-C 커넥터 또는 충전 pogo 접점 | 충전 입력 |
| D_esd/보호 | 입력 ESD/역전압 보호 | 충전 포트 보호 |
| SW1–4 | 택트 스위치 | 액션 버튼 |
| ENC1 | 증분형 로터리 엔코더(푸시형) | A/B + 푸시 |
| R_sense/설정 | nPM1100 전압/충전전류 설정 저항 | 데이터시트 스트랩 |
| 안테나/정합 | 칩/PCB 안테나 + π 매칭 | nRF54L15 레퍼런스 |
| LED(선택) | 저전류 LED/백라이트 | 피드백·충전상태 |
| C_dec 등 | 디커플링/입출력 커패시터 | nPM1100 벅 입출력 포함 |

> 배터리 잔량 표시가 필요하면 VBAT 을 MCU ADC 로 분압 측정(고저항 분압 + 필요 시
> 게이팅으로 누설 최소화). 정밀 퓨얼게이지가 필요하면 nPM1300 로 상향.
